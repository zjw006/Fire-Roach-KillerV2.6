# 《蟑螂猎手》游戏设计文档 (GDD)

> 版本: 1.0 | 更新日期: 2025-01-09 | 引擎: HTML5 Canvas 2D

---

## 1. 游戏概述

### 1.1 游戏名称
**蟑螂猎手 (Roach Blaster)**

### 1.2 游戏类型
2D俯视视角塔防射击游戏 / 解压清版射击

### 1.3 核心玩法
玩家控制一把烈焰喷射器，坚守屏幕底部的防线，消灭一波波从屏幕上方涌来的蟑螂大军。通过击杀蟑螂获得金币，拾取战场掉落的特殊道具，升级武器能力，抵御越来越强的敌人攻势。

### 1.4 目标平台
Web浏览器（桌面端 + 移动端）

### 1.5 技术栈
- **前端**: React + TypeScript + Tailwind CSS
- **渲染**: HTML5 Canvas 2D
- **音频**: Web Audio API（程序化音效合成）
- **反馈**: Vibration API（移动端震动）
- **存储**: localStorage（进度持久化）

### 1.6 核心体验
**爽快感 + 策略性** — 通过以下设计实现：
- 即时喷火的直观操作 + 物理粒子特效
- 6种道具的差异化战术选择
- 7种蟑螂的独特行为带来不同挑战
- 波次递增的压力感 + 道具释放的解压感

## 3. 防线系统

### 3.1 防线位置
- Y轴位置: `screenHeight * 0.85`
- 颜色: 根据场景变化（红色系渐变）

### 3.2 防线HP
- 初始HP: 100
- 简单模式: 防线HP 80
- 困难模式: 防线HP 60

### 3.3 突破机制
蟑螂到达防线Y坐标时：
- 扣除防线HP（1-3点/只）
- 触发屏幕震动（强度10）
- 播放突破音效 + 红色浮动文字提示
- 蟑螂死亡消失

### 3.4 游戏结束条件
防线HP ≤ 0 时进入 GAME_OVER 状态，显示结算界面。

## 4. 玩家系统

### 4.1 玩家位置
- X: 鼠标/触摸位置
- Y: 防线位置 (defenseLineY)

### 4.2 烈焰喷射器（主武器）
- **伤害**: 20/秒
- **射程**: 火焰长度150px
- **攻击范围**: 扇形散射，角度约60度
- **特殊效果**: 点燃蟑螂（持续灼烧3秒，共30点伤害）

### 4.3 玩家输入
- **开火**: 按住屏幕/鼠标左键
- **瞄准**: 移动鼠标/手指位置控制X轴
- **暂停**: 右上角暂停按钮

## 5. 蟑螂系统

### 5.1 蟑螂类型总览

| 类型 | 名称 | HP | 速度 | 体型 | 核心威胁 |
|------|------|-----|------|------|---------|
| **SMALL** | 小蟑螂 | 1 | 1.0 | 28px | 数量多，成群出现 |
| **LARGE** | 大蟑螂 | 4 | 0.8 | 40px | 血量厚，愤怒加速 |
| **FLYING** | 飞行蟑螂 | 2 | 1.5 | 32px | 飞行轨迹，俯冲攻击 |
| **ARMORED** | 装甲蟑螂 | 12 | 0.5 | 76px | 护甲减伤50% |
| **SPLITTING** | 分裂蟑螂 | 6 | 0.7 | 36px | 死亡分裂5只小蟑螂 |
| **SUICIDE** | 自爆蟑螂 | 2 | 0.6 | 60px | 范围爆炸伤害 |
| **QUEEN** | 蟑螂女王 | 200 | 0.4 | 120px | BOSS，召唤小怪 |

### 5.2 蟑螂详细设计

#### 小蟑螂 (SMALL)
- **描述**: 最基础的蟑螂单位，体型小速度快，成群出现
- **特殊能力**: 无
- **行为**: 直线向防线移动，轻微摆动
- **击杀奖励**: 2金币

#### 大蟑螂 (LARGE)
- **描述**: 体型庞大，血量多，愤怒时会加速冲刺
- **特殊能力**: 愤怒加速（HP低于50%时速度+50%）
- **行为**: 被攻击后进入愤怒状态
- **击杀奖励**: 10金币

#### 飞行蟑螂 (FLYING)
- **描述**: 拥有翅膀，从空中快速掠过
- **特殊能力**: 飞行（不受地面陷阱影响）+ 俯冲攻击
- **行为**: 在空中飞行（有altitude属性），到达防线后俯冲
- **击杀奖励**: 8金币

#### 装甲蟑螂 (ARMORED)
- **描述**: 厚重甲壳，护甲可吸收50%伤害
- **特殊能力**: 护甲系统（12HP护甲，护甲破后暴露本体12HP）
- **行为**: 缓慢推进，护甲破损后速度加快
- **击杀奖励**: 15金币

#### 分裂蟑螂 (SPLITTING)
- **描述**: 死亡后分裂出5只小蟑螂
- **特殊能力**: 分裂（死亡时生成5只小型蟑螂）
- **行为**: 正常移动，死亡瞬间触发分裂
- **击杀奖励**: 主蟑螂15金币 + 分裂体各2金币

#### 自爆蟑螂 (SUICIDE)
- **描述**: 背着炸弹的巨型蟑螂，靠近防线会爆炸
- **特殊能力**: 范围爆炸（半径100px，对范围内所有蟑螂造成伤害）
- **行为**: 缓慢移动，到达防线或死亡时爆炸
- **击杀奖励**: 20金币

#### 蟑螂女王 (QUEEN)
- **描述**: 所有蟑螂的首领，终极BOSS
- **特殊能力**: 召唤小怪 + 三阶段战斗 + 50%伤害减免
- **行为**: 三阶段：召唤期→飞行期→狂暴期
- **击杀奖励**: 500金币

### 5.3 蟑螂通用行为

#### 5.3.1 移动
- 基础移动: 朝向防线直线移动
- 摆动效果: 每个蟑螂有独立的wobbleOffset和wobbleSpeed，产生自然的摆动
- Panic状态: 被火焰灼烧时随机方向逃窜

#### 5.3.2 状态
```typescript
interface Roach {
  state: 'ALIVE' | 'DEAD' | 'BURNING'
  hp: number
  maxHp: number
  speed: number
  baseSpeed: number
  burnDamage: number  // 灼烧伤害
  inFire: boolean     // 是否在火焰中
  stunTimer: number   // 眩晕时间
  fanSlowTimer: number // 风扇减速时间
  fanSlowFactor: number // 风扇减速系数
  fanPushY: number    // 风扇吹退累积位移
}
```

#### 5.3.3 动画
- 死亡动画: 化为灰烬粒子消散
- 灼烧动画: 红色闪烁 + 烟雾粒子
- 飞行动画: 翅膀扇动（4帧循环，每帧0.12秒）

## 6. 道具系统

### 6.1 道具总览

| 道具 | 名称 | 效果 | 持续时间 | 伤害类型 |
|------|------|------|---------|---------|
| **sticky** | 蟑螂贴板 | 10个追踪水滴，黏住蟑螂无法移动 | 永久（直到目标死亡） | 控制 |
| **poison** | 杀虫剂喷雾 | 120度扇形毒雾，持续伤害+中毒 | 2秒 | 范围毒伤 |
| **fan** | 强力风扇 | 减速+向后吹退所有蟑螂 | 8秒 | 控制 |
| **molotov** | 燃烧瓶 | 自动找蟑螂形成火焰墙 | 5秒 | 持续区域伤害 |
| **shotgun** | 散弹模式 | 三方向扇形火焰散射 | 10秒 | 爆发 |
| **radar** | 雷达激光 | 自动追踪激光攻击最近蟑螂 | 5秒 | 单体高伤 |

### 6.2 道具详细设计

#### 蟑螂贴板 (STICKY)
- **触发方式**: 即时释放
- **效果**: 从防线中央发射10个黄色追踪水滴
- **追踪逻辑**: 水滴自动寻找最近的未黏住蟑螂
- **命中效果**: 蟑螂被黄色凝胶包裹，无法移动
- **持续**: 直到黏住的蟑螂死亡
- **视觉**: 黄色凝胶Blob + 内部气泡 + 表面反光
- **解锁关卡**: 第1关（初始道具）

#### 杀虫剂喷雾 (POISON)
- **触发方式**: 即时释放
- **效果**: 从防线中央向上喷射120度扇形毒雾
- **伤害**: 每0.3秒一次伤害结算，伤害随距离衰减
- **中毒效果**: 附加4秒中毒（每秒1.5持续伤害）
- **持续**: 2秒
- **视觉**: 绿色扇形渐变 + 粒子特效 + 脉冲闪烁
- **解锁关卡**: 第2关

#### 强力风扇 (FAN)
- **触发方式**: 即时释放
- **减速效果**: 按体型递减（飞行70% > 小60% > 大40% > 自爆30% > 装甲20% > 女王10%）
- **吹退效果**: 按体型递减（飞行120px/s > 小80 > 大50 > 分裂50 > 自爆35 > 装甲25 > 女王15）
- **持续**: 8秒
- **视觉**: 底部70%宽度的扇形透视气浪，向上收窄至8%
- **解锁关卡**: 第2关

#### 燃烧瓶 (MOLOTOV)
- **触发方式**: 即时释放
- **效果**: 自动寻找最近蟑螂位置，在其Y坐标形成横向火焰墙
- **范围**: X轴覆盖屏幕30%-70%，高度10px
- **伤害**: 经过的蟑螂持续受到伤害
- **持续**: 5秒
- **视觉**: 分段动画火焰 + 白热线芯 + 火星粒子
- **解锁关卡**: 第3关

#### 散弹模式 (SHOTGUN)
- **触发方式**: 即时释放
- **效果**: 主火焰 + 两侧各一束扇形火焰，共三方向
- **伤害**: 主火焰100%，侧火焰60%
- **持续**: 10秒
- **视觉**: 三束金色火焰，120度覆盖
- **解锁关卡**: 第4关

#### 雷达激光 (RADAR)
- **触发方式**: 即时释放
- **效果**: 自动锁定最近蟑螂，发射持续激光
- **伤害**: 每0.15秒攻击一次，50伤害/次
- **持续**: 5秒
- **视觉**: 粉色激光束 + 红色锁定框 + 电子扫描音效
- **解锁关卡**: 第5关

### 6.3 道具掉落
- 每25秒随机生成一个道具掉落物
- 道具类型受当前场景解锁限制
- 玩家移动到掉落物上自动拾取

## 7. 场景系统

### 7.1 场景总览

| 场景 | 名称 | 解锁条件 | 新蟑螂 | 新道具 |
|------|------|---------|--------|--------|
| **厨房** | 恐怖厨房 | 初始解锁 | 小蟑螂 + 大蟑螂 | 蟑螂贴板 |
| **下水道** | 阴暗下水道 | 通关厨房 | +飞行蟑螂 | +杀虫剂 +风扇 |
| **垃圾场** | 垃圾场 | 通关下水道 | +装甲蟑螂 | +燃烧瓶 |
| **地下室** | 地下室 | 通关垃圾场 | +分裂蟑螂 +自爆蟑螂 | +散弹模式 |
| **天台** | 天台决战 | 通关地下室 | +蟑螂女王 | +雷达激光 |
| **街道** | 城市街道 | 默认解锁(无尽专属) | 全部 | 全部 |

### 7.2 场景难度递增

每关10波，难度参数递增：
- 蟑螂数量: 逐波增加（第1波约10只 → 第10波约50只）
- 速度系数: 逐波增加（0.4 → 1.2）
- 生成间隔: 逐波缩短（12秒 → 4秒）
- 集群概率: 逐波提高（0% → 65%）

### 7.3 无尽模式难度
- 基于天台决战的波次配置
- 超出10波后每波按比例增强（+15%数量，+5%速度）

## 8. BOSS战系统

### 8.1 蟑螂女王

#### 基础属性
- HP: 200
- 速度: 0.4
- 体型: 120px
- 伤害减免: 50%

#### 三阶段

**第一阶段（HP 100%~70%）**: 召唤期
- 每8秒召唤3只小蟑螂
- 正常向防线移动

**第二阶段（HP 70%~40%）**: 飞行期
- 开始飞行（空中移动）
- 召唤间隔缩短

**第三阶段（HP 40%以下）**: 狂暴期
- 速度大幅提升
- 召唤频率最高
- 红色警告闪烁

#### 视觉表现
- 体型是普通蟑螂的4倍
- 紫色/粉色主题
- 三阶段颜色变化
- 召唤时紫色光环特效

## 9. 视觉特效系统

### 9.1 粒子系统

| 粒子类型 | 触发条件 | 视觉表现 |
|---------|---------|---------|
| **火焰粒子** | 喷火器开火 | 橙黄色渐变，向上飘散 |
| **死亡灰烬** | 蟑螂死亡 | 灰色粒子，向上飘散后下落 |
| **中毒粒子** | 杀虫剂命中 | 绿色粒子，从蟑螂身上飘出 |
| **爆炸粒子** | 自爆蟑螂/燃烧瓶 | 橙色+红色，向四周散射 |
| **激光粒子** | 雷达激光命中 | 粉色粒子，沿激光方向 |
| **黏胶粒子** | 贴板命中 | 黄色粒子，黏在蟑螂身上 |
| **风扇气流** | 风扇激活 | 紫色波浪线，底部大向上小 |

### 9.2 屏幕特效

| 特效 | 触发条件 | 强度 |
|------|---------|------|
| **屏幕震动** | 防线被突破/自爆/新纪录 | 2-12 |
| **浮动文字** | 击杀/道具使用/突破防线 | 彩色渐变 |
| **伤害闪烁** | 蟑螂受伤 | 红色0.1秒 |
| **慢动作** | 大规模爆炸 | 时间缩放0.5 |

### 9.3 风扇透视气浪特效
- **形状**: 底部70%屏幕宽 → 顶部8%宽（锥形透视）
- **波浪线**: 18条正弦波，从防线向上延伸，带透视收窄
- **阵风前沿**: 5道水平推进波，从底部向上扇形推进
- **微粒**: 28个上升粒子，底部分布广，越上越集中
- **轮廓线**: 扇形锥体边界线
- **光源**: 防线处径向紫色渐变

## 12. 对话系统

### 12.1 概述
剧情模式中每关开始前播放对话，介绍新蟑螂和新道具。

### 12.2 对话角色
- **蟑叔**: 装备供应商兼导师，幽默风趣
- **螂老大**: 蟑螂女王，反派角色
- **玩家**: 沉默主角

### 12.3 对话流程
1. 显示背景图 + 对话框
2. 逐字打字效果（每30ms一个字符）
3. 每句对话有情绪标签（影响头像表情）
4. 玩家可点击跳过或加速
5. 对话结束后进入游戏

## 13. 进度系统

### 13.1 存储内容
- `highestWave`: 剧情模式最高通关波次
- `highestEndlessWave`: 无尽模式最高波次
- `totalKills`: 总击杀数
- `scenesUnlocked`: 已解锁场景列表
- `scenesCompleted`: 已通关场景列表

## 15. 技术实现要点

### 15.1 游戏循环
```
requestAnimationFrame loop:
  1. Process input (mouse/touch)
  2. Update game state (deltaTime based)
  3. Update enemies movement
  4. Check collisions
  5. Update particles
  6. Render frame
```

### 15.2 性能优化
- 粒子数量上限: 200
- 蟑螂数量上限: 100
- 使用对象池复用粒子
- deltaTime固定上限16ms防止跳帧

- 触摸事件代替鼠标事件
- UI元素放大（最小44x44px触摸区域）
- 震动反馈仅在移动端启用
