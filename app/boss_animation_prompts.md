| 精细度 | 5 |
| 运动强度 | 中（角色动画）/ 高（技能特效） |

### 批量生成建议

1. **先选一张基础形象作为首帧参考** — 上传 `boss_base_01.png` 作为风格参考
2. **按顺序生成** — 基础动作 → 技能动画 → 表情特写
3. **同技能连续生成** — 如召唤技能先S1蓄力再S2释放，确保连贯
4. **阶段转换选在最后生成** — 需要确认基础形态满意后再进化

### 在代码中使用

```typescript
// 根据游戏状态切换动画
if (boss.isCharging) {
  playAnimation('S4'); // 冲锋冲刺
} else if (bossBattle.phaseChanging) {
  playAnimation('S8'); // 阶段进化
} else {
  playAnimation('A2'); // 默认：翅膀扇动悬停
}
```
