# 火枪特效调参台 使用说明

`flamethrower-vfx.html` —— 火枪特效及天赋升级效果的可视化编辑器。页面渲染逻辑与游戏引擎逐行一致（`renderFireZones` / `renderMuzzleFlash` / `renderGunEvolution`），调好参数后导出 JSON，由 AI 助手写入游戏配置文件。

---

## 1. 打开方式

项目 dev server 运行后访问（项目端口为 **3000**，非 5173）：

```
http://localhost:3000/flamethrower-vfx.html
```

> 若页面显示异常或疑似旧缓存，按 **Ctrl + F5** 强制刷新。
> 页面在后台标签页时 rAF 会暂停（画面静止），切回前台即恢复，属正常现象。

## 2. 界面布局

| 区域 | 位置 | 内容 |
|---|---|---|
| 画布 | 左侧 | 540×960 战斗画面实时预览（玩家锚点 270,1060，s=4） |
| 工具条 | 右侧面板顶部 | 场景/变体/状态开关/天赋开关 |
| 参数分组 | 右侧面板 | 12 个可折叠分组，滑杆 + 数字框 + 取色器 |
| 导出面板 | 右下角悬浮 | 实时 JSON、复制按钮、恢复内置数据 |

## 3. 顶部工具条

### 3.1 环境与状态

| 控件 | 作用 |
|---|---|
| 背景 | 超市/医院/地铁/巢穴/纯黑，检验特效在各场景下的可读性 |
| 火焰变体 | 默认 / 蓝焰核心 / 过载核心（对应天赋火焰配色） |
| 火力全开(强化) | 预览强化状态：枪口粒子喷射 + 火焰摆动加速 |
| 三重火焰 | 预览三枪并列（侧枪火焰/粒子/枪身同步展开） |
| 参考线 | 显示/隐藏画布上的标注层（见第 5 节） |
| 伤害强度 | 0~1.6 滑杆，预览伤害强度对火束宽度/透明度的渐进强化 |

### 3.2 天赋开关（预览升级效果）

| 天赋 | 当前视觉规则 |
|---|---|
| 扩口喷嘴 0-3 级 | 喷嘴圆环 1→2→3 个（**不**增加火焰长度） |
| 风压聚焦 0-3 级 | 涡轮增强·内吸波纹：相位推进时波纹由外向内收缩下沉（向枪口吸风）；不增加火焰长度 |
| 寒钢枪管 | 喷嘴圆环染色（当前为品红色，可配） |
| 聚能长枪 | 枪口聚能环（椭圆+底部缺口）+ 中心青色十字准星 |
| 过载核心 | 枪体深红脉动辉光 + 过载火焰配色 |

> 天赋等级开关只影响**视觉预览**，方便单独检验每个天赋的表现与参数。

## 4. 参数分组与配置文件映射

右侧面板共 12 个分组，标题后的括号标注了目标配置节：

| 分组 | 写入位置 |
|---|---|
| 玩家基准 | `enemies.ts` → `player` 节 |
| 火焰主体形态 | `vfx-balance.ts` → `render.fireZone` |
| 核心辉光 | `render.fireZone`（core*） |
| 火焰渐变·默认 / 蓝焰 / 过载 | `render.fireZone`（flameDefault*/flameBlue*/flameOverdrive*） |
| 枪口强化粒子 | `render.renderUtils.muzzleFlash` |
| 喷嘴锚点 & 扩口喷嘴白环 | `render.renderUtils.gunEvolution`（nozzle*） |
| 风压聚焦扩散波纹 | `gunEvolution`（focusRipple*） |
| 寒钢枪管染色 | `gunEvolution`（steelTint*） |
| 聚能长枪环 | `gunEvolution`（lanceRing*/lanceCross*） |
| 过载核心辉光 | `gunEvolution`（overdriveGlow*） |

### ⚠ 玩法参数（带 ⚠ 标注，改动影响伤害判定）

| 参数 | 影响 |
|---|---|
| `baseFireRange` 基础射程 | 火焰伤害距离基准 |
| `nozzleOffsetY` 喷嘴 Y 偏移 | 火焰起点，间接影响伤害区域位置 |
| `sideGunSpacing` 三重枪身间距 | 侧火焰伤害位置（写入 `items.ts tripleFlame.sideOffset`） |

纯视觉参数（长度比例/Y方向长度/宽度/颜色/透明度等）只改画面，不碰玩法。

## 5. 参考线标注层

勾选「参考线」后画布显示：

- **红色虚线**：防线位置（y=830）
- **蓝色十字 + 标注**：喷嘴锚点（`nozzleAnchorY`），右侧同时显示第一个喷嘴圆环的实测像素尺寸 `环 X:××px Y:××px`（拖白环半径/Y轴压扁时实时更新）
- **绿色十字 + 标注**：风压波纹 Y 锚点（`focusRippleYOffset`）
- **刻度线 + 文字**：火焰末端位置（= 射程 × 长度比例 × Y方向长度）

## 6. 调参 → 落地 工作流

1. 在页面上调整参数（画布实时预览，所有修改**自动保存**到浏览器 localStorage）
2. 用天赋开关/变体/背景做组合检验
3. 点击右下角「**复制 JSON**」
4. 把 JSON 发给 AI 助手，由其写入 `vfx-balance.ts` / `enemies.ts` / `items.ts` 并完成构建验证
5. 刷新页面后内置默认值会与新配置同步（见下）

### 本地保存机制

- 所有修改实时存入 localStorage（键含版本号 `DATA_VER`）
- 游戏配置更新后，页面内置默认值会同步更新并**递增 DATA_VER**，旧缓存自动失效，无需手动清理
- 「**恢复内置数据**」按钮：丢弃本地修改，回到与游戏配置一致的出厂值

## 7. 量纲与数值关系速查

- **玩家单位 vs 像素**：gunEvolution 分组全部使用「玩家单位」，渲染时 ×4（s=4）换算像素；fireZone/player 分组为像素
- **视觉火焰长度** = `baseFireRange` × 天赋射程倍率（仅寒钢/聚能计入）× `rangeRatio` × `flameLengthY`
  - 扩口喷嘴/风压聚焦的射程加成**不会**拉长火焰（按设计解耦）
  - 当前基准：220 × 0.65 × 0.75 ≈ 107px，短于伤害射程属刻意造型；想盖住伤害区就把乘积调到 ≈1
- **风压波纹频率** = `focusRippleFreqPerLevel` × 天赋等级（1级2 / 2级4 / 3级6 相位每秒）
- **火力全开摆动** = `wiggleFreq` / `wiggleTimeScale` 同乘 `boostWiggleFreqMult`

## 8. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 画面静止不动 | 标签页在后台，rAF 暂停；切回前台即可 |
| 参数好像没生效 | 浏览器缓存旧页面，Ctrl+F5 强刷 |
| 想回到最初状态 | 点「恢复内置数据」 |
| 调乱了某个分组 | 只把该分组的滑杆拖回默认值，或恢复内置数据后重来 |
| 导出 JSON 里缺少新参数 | 页面版本过旧，Ctrl+F5；DATA_VER 升级会自动处理 |
