# BOSS战完整流程文档

## 一、BOSS基础属性

| 属性 | 数值 | 说明 |
|------|------|------|
| 血量 | 10000 | 所有难度统一 |
| 蜕皮次数 | 3次 | 第1/2次蜕皮重生，第3次真正死亡 |
| 弱点-左眼 | 800 HP | 阶段二暴露，打爆后解锁右眼 |
| 弱点-右眼 | 800 HP | 左眼打爆后暴露，打爆后解锁腹部 |
| 弱点-腹部 | 1500 HP | 双眼打爆后暴露，打爆后扣除BOSS 30%最大HP |
| 护甲 | 5点 | 有护甲时减伤50%，弱点暴露时护甲归零 |
| 弱点伤害倍率 | 2x | 攻击弱点区域时伤害翻倍 |
| 蜕皮后加速 | +50% | 每次蜕皮后移速提升 |

## 三、弱点系统详细流程

### 弱点暴露顺序（严格线性，不可逆转）

```
阶段一开始：无弱点（攻击无效）
     │
     ▼ 阶段二转换
阶段二开始：【左眼准星】出现（BOSS头部左侧）
     │
     ├── 攻击左眼准星区域 → 左眼HP减少
     │
     ▼ 左眼HP降至0
左眼打爆：爆裂贴图 + 粒子特效 + "左眼打爆!"
     │
     ├── 左眼准星消失，右眼准星出现（800ms延迟）
     │
     ▼ 右眼准星出现
右眼激活：【右眼准星】出现（BOSS头部右侧）
     │
     ├── 攻击右眼准星区域 → 右眼HP减少
     │
     ▼ 右眼HP降至0
右眼打爆：爆裂贴图（水平翻转）+ "右眼打爆!"
     │
     ├── 右眼准星消失，腹部准星出现（800ms延迟）
     │
     ▼ 腹部准星出现
腹部激活：【腹部准星】出现（BOSS胸口中央）
     │
     ├── 攻击腹部准星区域 → 腹部HP减少
     │
     ▼ 腹部HP降至0
腹部重创：扣除BOSS 30%最大HP + "腹部重创! BOSS濒死!"
```

### 准星视觉效果

| 状态 | 左眼 | 右眼 | 腹部 |
|------|------|------|------|
| **未激活** | 灰色准星 | 隐藏 | 隐藏 |
| **激活** | 绿色脉冲+文字 | 绿色脉冲+文字 | 绿色脉冲+文字 |
| **打爆** | 爆裂贴图+红X | 爆裂贴图(翻转)+红X | 红X |

### 弱点位置坐标（相对BOSS中心）

| 弱点 | X偏移 | Y偏移 | 说明 |
|------|-------|-------|------|
| 左眼 | -30% | -12% | 头部左侧 |
| 右眼 | +30% | -12% | 头部右侧 |
| 腹部 | 0% | +20% | 胸口正下方 |

## 四、BOSS攻击模式

### 1. 召唤攻击

| 阶段 | 间隔 | 配置 |
|------|------|------|
| 一 | 10秒 | 3波递增（小蟑→大蟑→混合） |
| 二 | 10秒 | 6小+3大+3飞+3护甲 |
| 三 | 12秒 | 3自爆+3分裂+6小+3护甲 |

**召唤动画**：
- 触发时播放summon动画2.5秒
- BOSS身体震动 + 紫色能量脉冲
- 召唤完成后暴露对应弱点（右眼）

### 2. 冲锋攻击

```
触发条件：
  阶段二：30%概率，每4秒判定一次
  阶段三：50%概率，每2.5秒判定一次

执行流程：
  1. 瞳孔变红（1.5秒/简单，1.0秒/困难）
  2. 地面红色虚线预警（流动动画）
  3. 直线下冲至防线
  4. 冲撞防线造成伤害
  5. 300ms后返回原位

可被中断：
  • 电蚊拍命中 → 立即停止+左眼高亮
  • 蟑螂贴板命中 → 立即停止+减速90%

伤害：
  阶段二：20点防线伤害
  阶段三：35点防线伤害
```

### 3. 地面巡逻（阶段二/三）

- 巡逻范围：±250px
- 速度：基础速度 × 1.5（阶段二）/ × 2.5（阶段三）
- 动画：idle（待机）↔ walk（行走）切换
- 行走时有步伐弹跳+灰尘粒子

## 五、玩家攻击逻辑

### 攻击伤害计算流程

```
玩家开火 ──▶ 子弹/激光生成 ──▶ 碰撞检测 ──▶ 弱点判断 ──▶ 伤害计算
                                                              │
                                    ┌─────────────────────────┘
                                    ▼
                    ┌──────────────────────────────┐
                    │ 阶段一？                      │
                    │   → 是：伤害 = 0（无效）      │
                    │   → 否：继续                  │
                    └──────────────────────────────┘
                                    │
                                    ▼
                    ┌──────────────────────────────┐
                    │ 当前activeWeakPoint是什么？    │
                    │                              │
                    │ leftEye  → 伤害打在左眼       │
                    │ rightEye → 伤害打在右眼       │
                    │ belly    → 伤害打在腹部       │
                    │ ''       → 伤害 = 0（无效）   │
                    └──────────────────────────────┘
                                    │
                                    ▼
                    ┌──────────────────────────────┐
                    │ 对应弱点HP -= 伤害            │
                    │                              │
                    │ HP <= 0？                     │
                    │   → 是：弱点打爆，进入下一级   │
                    │   → 否：继续累积伤害          │
                    └──────────────────────────────┘
```

### 各武器对弱点效果

| 武器 | 弱点伤害倍率 | 特殊效果 |
|------|-------------|---------|
| 火焰喷射器 | 2x | 持续灼烧 |
| 雷达激光 | 2x | 弱点位置对齐准星 |
| 电蚊拍 | 2x | 可打断冲锋 |
| 子弹 | 2x | 基础攻击 |

### BOSS受击视觉效果

| 效果 | 描述 |
|------|------|
| 身体变红 | 亮度+50%，饱和度×2，红色色调偏移 |
| 红色覆盖 | 半透明红色叠加层（最高60%透明度） |
| damageFlash | 2.0（普通怪物为0.15） |
| 粒子 | 绿色火花（弱点命中）/ 红色火花（普通） |
