# 火枪升级效果方案

> 版本：v1.0（2026-08-20）
> 范围：天赋系统 → 喷火枪外观/特效随数值提升的视觉反馈
> 状态：路线 1（Canvas 程序化）+ 路线 2（贴图分级）均已实施，构建通过

---

## 一、方案目标

让玩家在天赋树中每投入 1 点，都能直观看到火枪"变强了"：

- **普通天赋** → 量变反馈（火焰更旺/更聚、枪身加装部件），无级渐进
- **基石天赋** → 质变反馈（火焰变色、枪管变形），一次性跳变
- **高投入形态** → 枪身贴图整体替换（mk1 / mk2），终局仪式感

## 二、现状盘点（实施前）

| 层级 | 天赋 | 实施前外观反馈 |
|---|---|---|
| 基石 | 蓝焰核心（bluecore）/ 过载核心（overdrive） | ✅ 火焰变蓝 / 深红紫 + 枪体脉动辉光 |
| 基石 | 寒钢枪管（steel）/ 聚能长枪（lance） | ✅ 喷嘴圆环染寒钢蓝 / 枪口聚能环+青色准星（火焰主体不再变化） |
| 普通 | 增压阀/高温燃料/爆燃增压（伤害线） | ❌ 无 |
| 普通 | 扩口喷嘴/风压聚焦（射程线） | ⚠️ 仅火束长度间接变长 |
| 普通 | 耐热合金/散热鳍片/扩容气罐（功能线） | ❌ 无 |

## 三、总体设计原则

1. **每点可见**：普通天赋按乘算超出部分（multiplier − 1）无级缩放视觉参数，不是离散跳变
2. **不覆盖基石**：普通点只调强度/尺寸/形态，变色/变形仍归基石专属
3. **性能红线**：
   - 粒子数量不增加（每帧仍 3 个，`countMin/countMax` 不动）
   - 透明度上限不提高（避免 lighter 叠加后火焰糊住下方蟑螂）
   - 只允许缩放：尺寸、宽度、张角、流速、占比
4. **参数集中**：所有系数存于 `vfx-balance.ts`，与现有特效管理规范一致

## 四、路线 1：火焰渐进强化（已实施）

### 4.1 驱动值

引擎每帧由天赋乘算折算两个强度值（`engine.ts → getFlameBoost()`）：

```
intensity = max(0, talentMultipliers.damageMultiplier − 1)   // 伤害强度（猛火系）
focus     = max(0, talentMultipliers.fireRangeMultiplier − 1) // 射程聚焦（长枪系）
```

满配参考：伤害乘算 ≈ 1.53（intensity ≈ 0.53）、射程乘算 ≈ 1.60（focus ≈ 0.60）。

### 4.2 伤害强度 → 火焰"旺"（猛火系）

| 视觉项 | 公式 | 满配效果 |
|---|---|---|
| 火焰/余烬粒子尺寸 | `size × (1 + intensity × 0.5)` | 约 +26% |
| 余烬占比 | `0.5 + intensity × 0.15` | 0.5 → 约 0.58（更饱满） |
| 火束渲染宽度 | `baseWidth × (1 + intensity × 0.15)` | 约 +8%（克制，不遮蟑螂） |

### 4.3 射程聚焦 → 火焰"聚"（长枪系）

| 视觉项 | 公式 | 满配效果 |
|---|---|---|
| 发射张角 | `angleSpread × max(0.5, 1 − focus × 0.35)` | 约 −21%（火束更收敛） |
| 粒子流速 | `flowSpeed × (1 + focus × 0.3)` | 约 +18%（喷射更有力） |
| 火束长度 | 扩口喷嘴/风压聚焦已与视觉解耦（不拉长火焰）；仅寒钢枪管/聚能长枪射程仍拉长火焰 | 改由喷嘴白环/风压波纹表现 |

### 4.4 配置位置

`vfx-balance.ts → BALANCE_CONFIG.particle.coneFire.talentBoost`：

```typescript
talentBoost: {
  sizePerIntensity: 0.5,        // 粒子尺寸随伤害强度缩放
  emberRatioPerIntensity: 0.15, // 余烬占比提升
  spreadPerFocus: -0.35,        // 张角随射程聚焦收敛（保底 50%）
  flowPerFocus: 0.3,            // 流速随射程提升
},
```

### 4.5 生效范围

- 仅主武器 `flamethrower` 的主火焰调用传入 intensity/focus
- 毒气/冰冻/三联散弹等其它调用不受影响（不传参，默认 0）

## 五、路线 1：枪身部件进化（已实施）

`engine.ts → renderGunEvolution()` 扩展，Canvas 程序化绘制（个位数 fillRect/stroke，开销可忽略），配置集中在 `vfx-balance.ts → render.renderUtils.gunEvolution`。

## 六、路线 2：枪身贴图分级（已实施骨架，待美术替换）

### 6.1 切换规则（`engine.ts → getGunTier()`）

| 等级 | 贴图 | 触发条件 |
|---|---|---|
| 0 | `gun.png`（默认） | — |
| 1 | `gun_mk1.png` | 猛火系 + 长枪系合计投入 ≥ 8 点 |
| 2 | `gun_mk2.png` | 激活任一 T5 终端基石（过载核心/聚能长枪），或合计 ≥ 14 点 |

贴图加载失败/缺失时自动回退默认 `gun.png`。当前 mk1/mk2 为 gun.png 的占位复制件，替换文件即生效，无需改代码。

### 6.2 美术需求

**`public/assets/gun_mk1.png` — 中级改装形态**
- 在 gun.png 基础上做"加装感"：枪管略加粗加长、枪身加散热细节/管线缠绕
- 配色加少量铜色点缀，轮廓保持原剪影大方向（避免视觉判定违和）

**`public/assets/gun_mk2.png` — 终极改装形态**
- 大幅重装化：加长主枪管 + 辅助喷口、枪身装甲板、能量导管发光纹路
- 建议偏暖橙呼应火焰主题（冰蓝亦可），气罐外挂扩容

**规格要求（两张统一）**：
- 画布比例与原 `gun.png` 相同（渲染按 60×80 玩家单位缩放，锚点不变）
- 透明背景 PNG，垂直朝上朝向
- **喷嘴保持在贴图顶部约 1/10 处**（火焰从该处喷出，偏移会导致火口脱节）
- 手绘质感、与现有场景风格统一，避免高饱和赛博风

## 七、反馈密度地图（玩家视角）

| 操作 | 看到的反馈 |
|---|---|
| 点增压阀/高温燃料/爆燃增压 | 火焰逐渐变大变饱满 |
| 点扩口喷嘴/风压聚焦 | 射程提升但火焰不再变长：喷嘴白环 1→3 个 / 喷嘴风压扩散波纹加速 |
| 点耐热合金/散热鳍片/扩容气罐 | 无视觉特效（仅功能数值） |
| 点蓝焰核心 | 火焰变蓝（质变） |
| 点过载核心 | 火焰深红紫 + 枪体脉动辉光（质变） |
| 点寒钢枪管 | 喷嘴圆环染为寒钢蓝（质变，无独立特效层） |
| 点聚能长枪 | 枪口聚能环（椭圆压扁+底部缺口，中心青色十字准星），火焰主体不再变化（质变） |
| 双系合计 ≥8 点 | 枪身贴图整体升级（mk1） |
| 激活 T5 基石 / ≥14 点 | 枪身贴图终局形态（mk2） |

## 九、后续可调项

- 若火焰视觉过强/过弱：只调 `talentBoost` 四个系数与火束宽度系数 0.15，无需改逻辑
- 若部件位置与 mk1/mk2 新贴图不匹配：调 `gunEvolution` 中各 `*YOffset/*Width` 参数
- 若需三联专精侧枪发光等额外反馈：在 `renderGunEvolution` 内按 `trimastery` 等级追加即可
