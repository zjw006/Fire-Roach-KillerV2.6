# 火焰蟑螂杀手 · UI 布局编辑器使用说明

本工具为单文件 HTML 应用 `ui-editor.html`，用于在 **540 逻辑宽度画布** 上「所见即所得」地排版游戏 UI，导出 JSON 后回写到游戏脚本（如 `src/components/game/GameMenu.tsx`、`TitleScreen.tsx` 等）。

- 坐标原点：画布左上角 `(0,0)`
- 坐标体系：与游戏 canvas 绘制坐标完全一致，导出的 JSON 可直接换算为游戏内的绝对定位

---

## 一、打开方式

| 方式 | 说明 |
| --- | --- |
| 推荐：dev server | 项目端口为 **3000**，浏览器访问 `http://localhost:3000/ui-editor.html` |
| 直接双击 | 以 `file://` 打开本文件也可用（脚本会自动把 `/assets` 重写到同级 `public/assets`，图标可正常显示） |

> 上传的本地图片 / 界面截图仅保存在**本机浏览器 localStorage**，换浏览器或清缓存后会丢失。

---

## 二、界面布局

```
┌──────────────────────────── 顶部工具栏 ────────────────────────────┐
│ 添加元素 · 载入预设 · 底图 · 画布高 · 缩放 · 网格/吸附/安全区/窄屏 · 撤销/重做 · 导出/清空 │
├───────────┬──────────────────────────────┬────────────────────────┤
│  素材库    │          舞台（画布）          │   图层 + 属性面板        │
│ (左侧)    │          (中间)               │   (右侧)              │
└───────────┴──────────────────────────────┴────────────────────────┘
```

- **左侧素材库**：内置图标（UI 按钮 / 消耗品 / 掉落道具 / 武器物件 / 角色蟑螂），点击即添加到舞台；底部可上传本地图片。
- **中间舞台**：可编辑画布，元素在此拖拽、缩放、旋转。
- **右侧面板**：上半部分是图层列表，下半部分是选中元素的属性编辑区。

---

## 三、元素类型（共 5 种）

| 类型 | 图标 | 说明 |
| --- | --- | --- |
| 图片 `image` | 图 | 静态图素，可设置 `src`、尺寸、位置 |
| 文字 `text` | 文 | 文本，支持字号、颜色、粗体、对齐、行高、描边、颜色渐变 |
| 面板 `rect` | 板 | 圆角色块，用于底板/进度条槽等 |
| 按钮 `button` | 钮 | 可用图片（变成图片按钮）或「色块 + 文字」 |
| 选中区域 `hit` | 区 | 虚线框，**仅在编辑器可见，游戏内不显示**，用于定位关卡点击热区 |

---

## 四、基本操作

### 1. 选中
- 点击舞台上的元素，或点击右侧图层面板中的某一层。

### 2. 移动 / 缩放 / 旋转
- **移动**：鼠标拖拽；或选中后按方向键（按住 `Shift` 每次移动 10px）。
- **缩放**：拖动选中元素四周的 **8 个手柄**；按住 `Shift` 等比缩放。
- **旋转**：在右侧「属性 → 变换 → 旋转°」中设置。

### 3. 删除 / 复制 / 图层
- 删除：`Del`（或 `Backspace`）
- 复制：`Ctrl+D`
- 图层操作：右侧面板「顶 / ↑ / ↓ / 底」按钮，或直接拖拽图层排序。
- 显示 / 隐藏：图层条目左侧 `👁`。
- 锁定 / 解锁：图层条目右侧 `🔒`（锁定后不可选中/拖动）。
- **图层顺序 = 数组顺序，index 0 在最底层（后渲染的在上层）**。

### 4. 快速改文字
- 双击文字或按钮元素，可直接聚焦到「文字内容 / 按钮文字」输入框编辑。

---

## 五、添加元素

1. **文字 / 面板 / 按钮 / 选中区域**：点击顶部工具栏对应按钮。
2. **图片**：
   - 从左侧素材库点击某图标，添加到舞台。
   - 或点「上传本地图片」批量添加（多选）。

---

## 六、载入现有界面预设（重要）

顶部「载入现有界面」下拉框提供四个内置预设：

| 预设 key | 名称 | 对应脚本 |
| --- | --- | --- |
| `main_menu` | 主菜单 | `GameMenu.tsx` 主菜单部分 |
| `loading_title` | LOADING 载入界面 | `TitleScreen.tsx` |
| `scene_select` | 关卡选择界面 | `GameMenu.tsx` 关卡选择部分 |
| `shop` | 商店界面 | `ShopScreen.tsx` |

- 载入会**替换当前画布内容**（可用「撤销」恢复）。
- 预设中的元素大多带 `bind` 标识（见下节），调整后导出 JSON 即可回写游戏。

---

## 七、`bind` 回写标识

`bind` 是编辑器元素与游戏脚本之间的关联标识，例如：

- `menu.story` / `menu.shop` / `menu.talent` …（主菜单按钮）
- `scene.hit.0` / `scene.stars.0` / `scene.label.0` …（关卡选择节点）
- `loading.anim` / `loading.logo` / `loading.mute` …（LOADING 界面）
- `shop.bg` / `shop.back` / `shop.card.*` / `shop.icon.*` / `shop.name.*` / `shop.price.*` / `shop.buy.*` / `shop.owned*` …（商店界面）

选中已绑定的按钮/热区时，属性面板会显示「绑定按钮 / 绑定区域」提示框。**拖动、换图后导出 JSON 即可回写，点击功能不受影响。**

---

## 八、属性面板

选中元素后，右侧属性面板按类型显示：

### 变换（所有类型）
- X / Y / 宽 / 高 / 旋转° / 不透明度
- 「水平居中」「垂直居中」快捷键

### 样式（按类型）
- **图片 / 按钮**：更换内置素材、上传本地图片替换、素材路径、还原原始尺寸；按钮额外可「清除图片（恢复色块）」。图片还支持 **九宫格（9-slice）**：启用后设置「上 / 右 / 下 / 左」切片边距，四角锁定原图素大小、中间拉伸补齐，缩放元素时圆角/边框不变形。
- **文字**：文字内容、字号、颜色、对齐、粗体、行高，以及 **描边**（描边色 / 描边宽）和 **颜色渐变**（渐变起色 / 渐变止色 / 渐变角度）。
- **面板 / 色块按钮**：填充色、描边色、描边宽、圆角；按钮额外有按钮文字、字号、文字色。
- **选中区域 hit**：填充色、描边色、描边宽（虚线框，仅编辑器可见）。

### 图层操作
- 复制（`Ctrl+D`）/ 删除（`Del`）。

---

## 九、底图（背景参考图）

「底图」下拉框用于铺一张参考图（放在所有元素之下，不拦截点击）：

- **内置背景**：各关卡场景图、棋盘格。
- **上传截图**：`＋ 上传游戏界面截图…`，会压缩为 540 宽 JPEG。
- **底图淡**：调节底图不透明度，方便对照摆放。
- **下载底图**：把当前截图导出为 `menu_bg.jpg`（供游戏作背景资源）。
- **移除自定义底图**：清除截图。

> 界面截图底图（`bgCustom`）是本地 dataURL，**不随 JSON 导出**。

## 十、画布高度

顶部「画布高」下拉框：

- `800`（短屏）/ `960`（标准，默认）/ `1080`（长屏）/ `自定义…`

## 十一、辅助开关

| 开关 | 作用 |
| --- | --- |
| 网格 | 显示 10px 网格 |
| 吸附 | 移动/缩放按 10px 对齐 |
| 安全区 | 显示顶部 44px、底部 34px 的安全区虚线（避开刘海/底部条） |
| 窄屏 | 用黑色遮罩标出最窄 21:9 屏幕下左右各裁切约 64px 的区域，用于验证窄屏不裁掉关键元素 |

---

## 十二、导出 / 导入 JSON

点「导出 / 导入」按钮打开弹窗：

- **导出**：生成布局 JSON（坐标基于 540 逻辑宽度）。
- **复制 JSON**：一键复制到剪贴板。
- **下载 .json**：保存为 `ui-layout.json`。
- **导入下方 JSON**：粘贴之前导出的 JSON 恢复布局。

JSON 结构示例（节选）：

```json
{
  "app": "fire-roach-killer-ui",
  "version": 1,
  "stage": { "width": 540, "height": 960, "background": null },
  "elements": [
    { "type": "image", "bind": "menu.story", "name": "开始游戏", "src": "/assets/UI/btn_story_zh.png", "x": 270, "y": 254.6, "w": 205.9, "h": 75.4 }
  ]
}
```

> 把导出的 JSON 交给开发者即可写入游戏 UI 配置。

---

## 十三、自动保存

- 编辑内容会实时保存到浏览器 `localStorage`（key：`roach_ui_editor_v2`，约 300ms 防抖）。
- 关闭后再打开会自动恢复上次编辑状态。
- 历史记录最多保留 60 步。

## 十四、快捷键速查

| 操作 | 快捷键 |
| --- | --- |
| 移动（微调） | 方向键；`Shift` + 方向键 = 10px |
| 等比缩放 | `Shift` + 拖动手柄 |
| 删除 | `Del` / `Backspace` |
| 复制 | `Ctrl+D` |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y`（或 `Ctrl+Shift+Z`） |
| 取消选择 | `Esc` |

## 十五、常见注意点

1. **图片路径**：元素存储始终用 `/assets` 逻辑路径（导出回写游戏用）；`file://` 直开时会临时重写到 `public/assets` 显示，不影响存储。
2. **载入预设会替换画布**：误操作可用「撤销」恢复。
3. **上传图片仅存本机浏览器**：换浏览器 / 清缓存会丢失，重要素材请复制到 `public/assets/UI/`。
4. **`hit` 选中区域不会出现在游戏内**，只用于编辑器定位关卡点击热区。
5. **图层顺序**：index 0 最底层；需要某元素盖住另一元素时，把它上移（更靠后渲染）。
