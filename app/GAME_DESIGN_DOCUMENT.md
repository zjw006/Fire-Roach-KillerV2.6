## 1. 游戏概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 游戏名称 | 《烈焰除蟑》(Fire Roach Killer) |
| 游戏类型 | 固定视角射击塔防 / 动作休闲 |
| 目标平台 | Web (HTML5 Canvas) |
| 画面比例 | 540×960 (9:16 竖屏) |
| 技术栈 | TypeScript + Vite + React |
| 核心玩法 | 使用火焰喷射器及多种武器消灭从画面远端涌来的蟑螂群，守卫防线 |

### 1.2 游戏背景

玩家扮演一名"专业除蟑师"，在蟑螂泛滥的末日世界中，受雇于神秘商人"蟑叔"，使用各种武器清除蟑螂。游戏以幽默搞笑的对话风格推进剧情，蟑螂也被赋予了各种拟人化特征。

### 1.3 核心循环

```
选择关卡 → 观看剧情对话 → 战斗(逐波消灭蟑螂) → 波次结算 → 通关获得奖励 → 解锁新场景/武器 → 升级天赋 → 返回主菜单 → 主菜单商店购买道具（玩家自行决定） → 点击下一关进入下一关 / 点击重新挑战重玩本关 → 挑战更高难度
```

## 2. 游戏模式

### 2.1 故事模式 (Story Mode)

- 按固定顺序挑战 11 个场景
- 每个场景 6-8 波敌人
- 通关后解锁下一场景
- 首次通关获得新武器/道具奖励
- 支持"简单"和"困难"两种难度

### 2.2 无尽模式 (Endless Mode)

- 选择已解锁场景进行无限波次挑战
- 记录最长存活时间
- 难度随波次递增
- 达成新纪录时有特殊提示

### 2.3 每日挑战 (Daily Mode)

- 每日生成随机种子，所有玩家面对相同配置
- 固定场景和波次配置
- 适合竞技比拼

### 2.4 Boss 模式 (Boss Mode)

- 专为 Boss 战设计
- 对抗蟑螂女王
- 多阶段战斗机制

## 3. 核心玩法

### 3.1 玩家操作

| 操作 | 说明 |
|------|------|
| 鼠标移动 | 控制玩家水平移动位置 |
| 按住鼠标/触摸 | 使用火焰喷射器持续喷射 |
| 点击屏幕 | 触发道具放置、物品拾取 |
| 切换武器 | 循环切换已解锁武器 |
| 电蚊拍 | 点击按钮释放全屏电击 |

### 3.2 防线机制

- 画面底部有一条"防线"
- 防线初始 HP 为 80（受天赋加成影响）
- 蟑螂到达防线会减少防线 HP
- 防线 HP 归零则游戏失败
- 可通过消耗品"防线修复"恢复 20% HP
- 可通过消耗品"临时护盾"获得 5 秒无敌

### 3.3 燃气与过热系统

- **燃气 (Gas)**: 火焰喷射器的燃料，容量受天赋影响
- **过热 (Heat)**: 连续喷射会积累热量，达到阈值后进入过热状态
- **过热状态**: 暂时无法喷射，需等待冷却
- **冷却**: 自动恢复，速度受天赋影响

### 3.4 伤害计算

- 火焰伤害 = 基础伤害 × 武器倍率 × 距离衰减 × 天赋加成 × 难度倍率
- 火焰对飞行蟑螂有额外命中范围
- 装甲蟑螂的护甲吸收 50% 伤害
- 蟑螂女王有 50% 火焰抗性

## 5. 敌人系统

### 5.1 敌人类型总览

|------|------|-----|------|----------|------|----------|
| `small` | 小蟑螂 | 1 | 1.0 | 1 | 小 | 闪避（受火焰攻击时横向躲闪） |
| `large` | 大蟑螂 | 4 | 0.8 | 5 | 大 | 愤怒加速 50% |
| `flying` | 飞行蟑螂 | 2 | 2.4 | 4 | 中 | 飞行、闪避 |
| `armored` | 装甲蟑螂 | 12 | 0.5 | 8 | 超大 | 护甲 50% 减伤 |
| `splitting` | 分裂蟑螂 | 6 | 0.7 | 10 | 大 | 死亡分裂 5 只小蟑螂 |
| `suicide` | 自爆蟑螂 | 2 | 1.4 | 6 | 大 | Z字形游走靠近防线自爆、闪避（受火焰攻击时横向躲闪，速度 100px/s） |
| `flying_suicide` | 飞行自爆蟑螂 | 2 | 2.2 | 8 | 大 | 飞行+俯冲自爆 |
| `queen` | 蟑螂女王 | 100 | 0.3 | 100 | 巨大 | Boss, 召唤小蟑螂, 50%火抗 |
| `nurse` | 护士蟑螂 | 25 | 0.8 | 28 | 大 | 四阶段AOE治疗（idle→蓄力→喷射→消散），治疗360px范围内最低血量盟友20%最大HP；杀虫剂敏感（窒息8秒）；自带红色护盾（HP 25） |
| `mutant` | 变异蟑螂 | 8 | 0.5 | 22 | 中 | 死亡酸液溅射（100px范围，最高10伤害+灼烧）；死亡时胚胎暴走（7帧序列帧变形动画后生成2只蟑螂：50%小×2 / 30%小+飞行 / 20%小+自爆） |
| `timed_suicide` | 定时自爆蟑螂 | 30 | 1.4 | 40 | 大 | 放置炸弹前被杀死→尸体炸弹倒计时3秒后爆炸（120px范围，30伤害）；放置炸弹时无敌不受伤害；放置炸弹后定时自爆蟑螂变身大蟑螂冲击防线，炸弹3秒倒计时爆炸；自带护盾（HP 30）；受火焰攻击横向闪避（100px/s） |

### 5.2 敌人 AI 行为

- **移动**: 蟑螂在 6 点透视地面边界内随机游走，总体向防线方向移动
- **闪避**: 小蟑螂和自爆蟑螂具有闪避能力，受火焰攻击时会横向躲闪
- **愤怒**: 大蟑螂 HP 低于 50% 时速度提升 50%
- **飞行**: 飞行类蟑螂从屏幕两侧出现，有飞行高度，不受地面陷阱影响
- **护甲**: 装甲蟑螂有额外护甲 HP，护甲破损后露出本体
- **分裂**: 分裂蟑螂死亡时生成 5 只小蟑螂
- **自爆**: 靠近防线时爆炸，造成范围伤害
- **治疗（护士蟑螂）**: 四阶段状态机：idle（1 秒冷却）→ charging（蓄力 1.0 秒，立即治疗 360px 范围内最低血量盟友 20% 最大 HP，显示"非法行医!"和"治疗喷射!"）→ spraying（喷雾 2.0 秒，纯视觉效果）→ dissipating（消散 1.0 秒）。被治疗盟友显示绿色 + 号图标 2 秒。若无受伤盟友则重置计时器
- **杀虫剂敏感（护士蟑螂）**: 接触杀虫剂后窒息 8 秒（asphyxiationTimer），期间无法行动
- **变异（变异蟑螂）**: 死亡时触发两个效果：① 酸液溅射（100px 范围，最高 10 伤害 + 灼烧，最多连锁 3 层死亡链）；② 胚胎暴走——7 帧序列帧变形动画（200ms/帧，共 1.4 秒：正常 → 肿胀 → 爆裂），生成 2 只蟑螂（50% 小×2 / 30% 小+飞行 / 20% 小+自爆），子体带有绿色粘液覆盖（2 秒）和 1 秒生成无敌。变形期间（transformTimer）完全无敌
- **定时自爆（定时自爆蟑螂）**: 三种行为路径：① 放置炸弹前被杀死 → 尸体炸弹（3 秒倒计时，红色脉冲闪烁，每 0.5 秒警告 "!!"，120px 范围 30 伤害爆炸，屏幕震动强度 22）；② 到达防线前 64px → 放置炸弹（2 秒，期间无敌不受伤害，冻结在原地，清除所有 DoT）→ 放置完成后变身大蟑螂（HP/速度/体型改为大蟑螂属性）继续冲击防线，炸弹独立 3 秒倒计时后爆炸（屏幕震动强度 28，多层爆炸粒子特效）；③ "螂家爆破"防线爆破系统（警戒→蹲伏→爆炸→残渣）。自带护盾（HP 30），受火焰攻击时横向闪避（100px/s，持续 1.2 秒）

### 5.3 难度倍率

- **简单模式**: HP ×1.2, 速度 ×1.0
- **困难模式**: HP ×1.8, 速度 ×1.1

### 5.4 蟑螂数量上限

- 场上最多同时存在 40 只蟑螂

### 5.5 怪物行为动画

所有蟑螂使用精灵图（Sprite）渲染，支持动画帧切换。不同蟑螂类型有不同的动画表现：

| 怪物类型 | 默认动画 | 移动动画 | 特殊动画 |
|----------|----------|----------|----------|
| 小蟑螂 | 双足行走循环 | 触角摆动 + 腿部交替 | 闪避：横向快速平移（分裂子体 250px/s，普通 180px/s） |
| 大蟑螂 | 沉重步伐 | 缓慢爬行，HP < 50% 时加速并变红 | 愤怒：体型放大 + 身体变红 + 速度提升 50% |
| 飞行蟑螂 | 翅膀扇动悬停 | 空中飞行，翅膀高频振动 | 闪避：飞行中横向侧移；受击时翅膀停顿 |
| 装甲蟑螂 | 厚重甲壳移动 | 缓慢推进，甲壳反光 | 护甲破损：甲壳碎裂动画 → 暴露本体 |
| 分裂蟑螂 | 膨胀躯干 | 笨重爬行，腹部膨胀闪烁 | 死亡分裂：身体爆裂 → 5 只小蟑螂蹦出（分裂子体闪避速度 250px/s，持续 0.2-0.4 秒） |
| 自爆蟑螂 | 背着炸弹行走 | Z 字形游走，炸弹红光闪烁 | 闪避：火焰攻击时横向躲闪（100px/s，持续 1.2 秒）；爆炸：冲击波扩散 + 碎片粒子 |
| 飞行自爆蟑螂 | 飞行 + 背部炸弹 | 高速飞行，炸弹闪烁 | 俯冲自爆：急速下降 + 爆炸 |
| 蟑螂女王 | 7 帧 idle 循环（10fps） | 3 帧 hover 悬停（8fps） | 召唤：施法粒子特效；受伤：hurt 动画（8fps）；死亡：die 动画（4fps）；蜕皮：transform 动画（8fps） |
| 护士蟑螂 | 白色制服 + 红十字（`roach_nurse.png`） | 跟随盟友移动 | 治疗施法动画：10 帧序列帧（`nurse_cast_01.png` ~ `nurse_cast_10.png`），四阶段帧映射——① charging 蓄力（1.0s，帧 1-4，~250ms/帧）；② spraying 喷雾（2.0s，帧 5-7 循环，~600ms/周期）；③ dissipating 消散（1.0s，帧 8-10，~330ms/帧）。杀虫剂敏感：窒息抽搐 8 秒 |
| 变异蟑螂 | 绿色荧光闪烁（`roach_mutant.png`） | 缓慢爬行 | 变形（transformTimer）：1 秒无敌 + 绿色荧光脉冲。死亡胚胎暴走：7 帧序列帧变形动画（`mutant_01.png` ~ `mutant_07.png`，200ms/帧，共 1.4 秒）正常 → 肿胀 → 爆裂，渲染时 1.3 倍放大，屏幕震动（强度 12），红色冲击波，生成子体带绿色粘液覆盖（2 秒）和 1 秒冻结无敌。死亡酸液：酸液喷溅粒子 |
| 定时自爆蟑螂 | 背着炸弹（HP 30 护盾） | 快速移动，炸弹倒计时闪烁 | ① 尸体炸弹：被杀死后尸体留下炸弹，3 秒倒计时（红色脉冲闪烁 + 每 0.5 秒 "!!" 警告），爆炸（120px 范围，30 伤害，红色冲击波，屏幕震动 22）；② 放置炸弹：到达防线前 64px → 2 秒安放炸弹（冻结 + 无敌，金色粒子环绕）→ 变身大蟑螂（体型变大动画，显示"变身大蟑螂!"），炸弹独立 3 秒倒计时 → 爆炸（多层火焰 + 冲击波 + 碎片，屏幕震动 28）；③ 防线爆破：警戒→蹲伏→爆炸→残渣。闪避：火焰攻击时横向躲闪（100px/s，持续 1.2 秒） |

> 注：Boss 动画中 walk、charge、summon、defend、hit、die、roar、transform 等动作因美术资源尚未制作，帧数为 0，渲染时回退到 idle 动画。

## 6. 武器与技能系统

### 6.1 主武器：火焰喷射器

- 默认武器，始终可用
- 锥形火焰喷射

- 支持三连火焰模式（消耗品激活）

### 6.2 特殊武器/道具

| 武器 | 名称 | 持续时间 | 弹药量 | 冷却 | 回收价 | 说明 |
|------|------|----------|--------|------|--------|------|

| `poison` | 杀虫剂 | 15s | 40 | 6s | 8 | 喷射毒雾，对蟑螂造成持续伤害 |

### 6.3 武器掉落系统

- 战斗中每 25 秒自动生成一个武器掉落
- 掉落物在地上弹跳，有生命周期
- 玩家走过即可拾取
- 拾取后进入物品栏，可随时使用
- 同一武器可叠加数量

## 7. 道具与消耗品

### 7.1 主菜单商店消耗品

> 玩家在主菜单的商店界面（ShopScreen）购买消耗品，购买后携带进入关卡战斗。在关卡战斗中会显示已购买的道具库存，玩家手动使用。

| ID | 名称 | 价格 | 冷却 | 效果 |
|----|------|------|------|------|
| `gas_refill` | 气罐补给 | 250 | 3s | 立即回满燃气 |
| `defense_repair` | 防线修复 | 400 | 8s | 防线 HP +20% |
| `emergency_cool` | 紧急冷却 | 200 | 无 | 立即清除过热 |

#### 14.2.2 剧情模式详细流程

**阶段 1：战前准备**
1. 玩家在标题画面点击"开始游戏"
2. 进入场景选择界面（SceneSelectScreen），选择已解锁的场景
3. 进入准备界面（PreparationScreen），选择携带道具（已解锁的道具）、确认难度（简单/困难）
4. 进入主菜单商店界面（ShopScreen），用资金购买消耗品（气罐补给、防线修复、紧急冷却、火力全开、临时护盾、蟑螂诱饵），购买的道具将携带进入关卡战斗。此步骤由玩家自行决定是否购买，可跳过
5. 点击"开始战斗"

**阶段 2：剧情对话**
6. 显示蟑叔的搞笑对话（DialogConfig），每个场景有独特的开场白
7. 对话结束后自动进入战斗

**阶段 3：倒计时**
8. 游戏切换到 COUNTDOWN 状态
9. 屏幕中央显示 3 → 2 → 1 倒计时文字
10. 倒计时期间游戏逻辑暂停（蟑螂不移动、不生成）
11. 倒计时结束 → 切换到 PLAYING 状态

**阶段 4：战斗循环（每波）**
12. 波次开始，生成队列（spawnQueue）填充蟑螂
13. 按固定间隔（interval）逐个从队列中生成蟑螂
14. 玩家使用火焰喷射器 + 已购买的道具消灭蟑螂，道具栏显示在主菜单购买的消耗品库存，全部手动点击使用
15. 每 25 秒自动生成一个武器掉落物
16. 玩家可随时手动使用消耗品
17. 所有蟑螂被消灭 → 波次清除（waveJustCleared = true）
18. 显示波次统计：击杀数、赏金、消耗品使用情况

**阶段 5：波次结算（非最后一波）**
19. 切换到 WAVE_CLEAR 状态
20. 显示波次结算界面，展示击杀数、赏金
21. 查看道具库存（主菜单商店购买的道具）
22. 点击继续 → 回到阶段 3（COUNTDOWN），开始下一波

**阶段 6：战后奖励（最后一波）**
23. 切换到 ITEM_DROP 状态
24. 场景掉落奖励物品（解锁新武器/道具）
25. 物品在地上弹跳
26. 玩家点击物品 → 拾取 → 切换到 ITEM_REVEAL 状态
27. 蟑叔揭示物品，展示搞笑描述
28. 未使用的道具按回收价折现（sellUnusedInventory）
29. 保存进度（saveProgress）
30. 检查并解锁成就（checkAchievements）
31. 解锁下一场景（unlockNextScene）
32. 回到 MENU（主菜单），玩家可自行决定是否进入主菜单商店购买道具
33. 点击"下一关"→ 进入下一场景，回到阶段 1
34. 点击"重新挑战"→ 重新挑战本关，回到阶段 1

**阶段 7：游戏失败**
35. 任何时候防线 HP 归零 → 切换到 GAME_OVER 状态
36. 显示失败界面（GameOverScreen），展示失败原因
37. 未使用的道具按回收价折现
38. 保存进度
39. 点击"重新开始" → 回到阶段 1

#### 14.2.3 状态转换规则

| 当前状态 | 触发条件 | 下一状态 |
|----------|----------|----------|
| MENU | 点击开始 | 对话 → COUNTDOWN |
| COUNTDOWN | 倒计时结束 | PLAYING |
| PLAYING | 波次清除（非最后一波） | WAVE_CLEAR |
| PLAYING | 波次清除（最后一波） | ITEM_DROP |
| PLAYING | 防线 HP = 0 | GAME_OVER |
| WAVE_CLEAR | 玩家点击继续 | COUNTDOWN |
| ITEM_DROP | 玩家点击物品 | ITEM_REVEAL |
| ITEM_REVEAL | 揭示完成 | MENU |
| GAME_OVER | 玩家点击重试 | MENU |

## 18. 技术规格

### 18.1 引擎架构

- **旧引擎**: 单文件 10952 行 `GameEngine` 类
- **新引擎**: 模块化架构，拆分为多个子系统：
  - `EconomyManager` - 经济管理
  - `ProgressManager` - 进度管理
  - `WeaponManager` / `WeaponSystem` - 武器系统
  - `WaveManager` - 波次管理
  - `UIManager` - UI 管理
  - `PlayerControlSystem` - 玩家控制
  - `AchievementSystem` - 成就系统
  - `SaveSystem` - 存档系统
  - `ShopManager` - 商店管理
  - `StatsSystem` - 统计系统
  - `CollisionSystem` - 碰撞系统
  - `RoachAISystem` - 蟑螂 AI

### 18.2 渲染系统

- 使用 Canvas 2D API
- 540×960 逻辑分辨率
- 支持 DPR 缩放 (最高 2x)
- 透视渲染（景深效果）
- 分层渲染：背景 → 特效 → 实体 → 粒子 → UI 叠加

### 18.3 性能优化

- 动态粒子数量限制
- 护甲肉盾缓存（避免 O(n²) 检测）
- 帧时间采样与自适应调整
- 实体数量硬上限 (40 只蟑螂)
