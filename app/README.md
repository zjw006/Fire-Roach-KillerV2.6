# 🔥 烈焰除蟑：火线守卫

> **一款竖屏2D射击塔防游戏** · 玩家操控火焰喷射器抵御变异蟑螂大军的入侵

## 🚀 快速开始

### 环境要求
- Node.js 18+ 
- npm 9+ 或 yarn 1.22+
- MySQL 8.0+

### 安装步骤
```bash
# 克隆项目
git clone <repository-url>
cd Fire-Roach-KillerV2.6/app

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，配置数据库连接

# 初始化数据库
npm run db:push

# 启动开发服务器
npm run dev
```

### 访问地址
- **本地开发**: http://localhost:3000
- **构建预览**: http://localhost:8080
- **手机测试**: 使用本地IP地址（如 `http://192.168.x.x:8080`）

## 🎮 游戏特色

### 🎯 核心玩法
- **竖屏2D射击塔防** - 专为手机设计的操作体验

## 🐛 故障排除

### 常见问题
1. **端口被占用**
   ```bash
   # 检查占用端口的进程
   netstat -ano | findstr :3000
   
   # 终止进程
   taskkill /PID <进程ID> /F
   ```

2. **音频无法播放**
   - 确保点击页面任意位置触发用户交互
   - 检查浏览器控制台是否有错误
   - 验证音频文件路径是否正确

3. **数据库连接失败**
   - 检查 `.env` 文件配置
   - 确保MySQL服务正在运行
   - 验证数据库用户权限

4. **构建失败**
   - 清理构建缓存: `npm run clean`
   - 重新安装依赖: `rm -rf node_modules && npm install`
   - 检查TypeScript错误: `npm run check`

- **浏览器开发者工具**: 查看控制台日志和网络请求
- **Vite热重载**: 代码修改后自动刷新
- **TypeScript严格模式**: 提前发现类型错误
- **性能分析**: 使用Chrome DevTools的Performance面板

## 📊 性能优化

### 渲染优化
- **Canvas批处理**: 减少绘制调用
- **对象池**: 重用游戏对象，减少GC压力
- **视口裁剪**: 只渲染可见区域内的对象
- **纹理图集**: 合并小图片，减少HTTP请求

### 内存管理
- **资源懒加载**: 按需加载游戏资源
- **缓存策略**: 合理缓存常用资源
- **泄漏检测**: 定期检查内存泄漏

### 网络优化
- **资源压缩**: 使用Gzip/Brotli压缩
- **CDN加速**: 静态资源使用CDN分发
- **缓存头**: 合理设置HTTP缓存头
